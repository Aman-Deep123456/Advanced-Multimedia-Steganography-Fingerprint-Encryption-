Cryptographic Architecture

SECP256K1 Elliptic Curve: $y^2 = x^3 + 7 \pmod p$. Provides 128-bit quantum-resistant symmetric security equivalent.

ECIES Hybrid Encryption: The sender creates an ephemeral SECP256K1 keypair, performs Diffie-Hellman exchange with the recipient's public key, and derives a 32-byte AES-GCM key via HKDF-SHA256.
